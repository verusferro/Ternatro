# Balatro for Tern (window half)

`tern plugin link <repo>/plugin` (keep it linked; run `balatro-tern setup` first, see the main README).
Palette: **Balatro: New Run** / **Balatro: Continue** open the game beside the focused pane. A `\\wsl…` link runs it in WSL.
Status line: ante and money of `Balatro: …` panes.
